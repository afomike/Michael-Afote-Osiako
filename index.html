Accidental Fall Prediction & Detection

The Problem

Falls are the second leading cause of accidental death globally. In low-resource clinical settings, fall risk is assessed manually and infrequently — meaning high-risk patients go unmonitored between assessments. A real-time early-warning system could meaningfully reduce mortality and caretaker response time.

Approach

Six classifiers benchmarked: Logistic Regression, Decision Tree, Random Forest, SVM, AdaBoost, and Bagging SVC. Bagging SVC was selected for production — it delivered the best precision-recall balance in a medical context where false negatives carry far higher cost than false positives.

Deployment

Model serialised with joblib, served via Flask REST API. The front-end sends sensor readings as JSON; the API returns a risk classification and, if high risk is detected, dispatches an SMS to the registered caretaker. Full stack deployed on Render with a persistent worker process.
